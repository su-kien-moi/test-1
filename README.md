## 🎯 Giới thiệu

Đây là trang web tĩnh (HTML + CSS + JavaScript thuần, không dùng thư viện ngoài) được thiết kế để chúc mừng **Ngày Nhà giáo Việt Nam 20/11**. Trang web bao gồm:

- Màn hình mở đầu với nút play hình tròn, bên trong là tam giác bo góc.
- 100 bông hoa tulip 🌷 bay lên liên tục, lệch nhịp như những ngôi sao.
- 160 ngôi sao nền lấp lánh.
- 100 dòng lời chúc chạy từ dưới lên trên màn hình.
- Một khối lời chúc bằng tiếng Trung ở cuối.
- Nhạc nền không lời (tùy chọn).

---

## ✨ Tính năng

| Tính năng | Mô tả |
|---|---|
| 🎬 **Màn hình mở đầu** | Nút tròn ở giữa với icon tam giác bo góc, bấm để bắt đầu |
| 🌷 **100 bông hoa tulip bay** | Bay liên tục, mỗi bông có tốc độ và quỹ đạo riêng |
| ⭐ **160 ngôi sao nền** | Nhấp nháy ngẫu nhiên, tạo không gian lung linh |
| 📜 **100 dòng văn bản chạy** | Tự động chạy từ dưới lên, tốc độ tự tính theo độ dài |
| 🇨🇳 **Khối lời chúc tiếng Trung** | Nổi bật với khung viền vàng và hiệu ứng phát sáng |
| 🎵 **Nhạc nền** | File `music.mp3`, tự động phát sau khi bấm nút |
| 📱 **Responsive** | Tự co giãn theo mọi kích thước màn hình |
| ⌨️ **Hỗ trợ bàn phím** | Bấm `Enter` hoặc `Space` để bắt đầu |
